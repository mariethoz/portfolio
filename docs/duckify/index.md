# 🦆 **Duckify**
[Project](https://github.com/Toys-R-Us-Rex/Duckify): AI‑Generated Duck Drawing with Robot Arm

We’re building a system that takes an image generated by AI and has a robot arm physically draw it onto a 3D duck. The process involves generating the artwork, converting it into paths the robot can follow, preparing the physical duck and pen setup, and controlling the robot so it can draw accurately on curved surfaces using multiple colors.
